# 储能与经济回测协议

## 目的

本协议用于检验 NSW1 RRP 概率预测能否转化为小型表后储能的样本外运营价值。它是研究模拟，不代表真实设备、用户合同、市场接入或商业收益。

第一阶段分离两个问题：

1. 在纯价格信号下，不同预测模型是否导致更好的充放电决策？
2. 在合成负荷、光伏和 NMI 约束下，这种改善是否仍然存在？

## 基准资产

第一阶段基准资产固定为：

| 参数 | 基准值 | 说明 |
|---|---:|---|
| 额定充电功率 | 10 kW | 对称基准 |
| 额定放电功率 | 10 kW | 对称基准 |
| 可用能量窗口 | 20 kWh | 用户已确认的研究容量 |
| 推导毛能量 | 25 kWh | 使 10%-90% SOC 窗口对应 20 kWh |
| 安全 SOC 下限 | 10% | 硬约束 |
| 安全 SOC 上限 | 90% | 硬约束 |
| 市场可调用备用下限 | 20% | 默认市场运营不低于此值 |
| 初始 SOC | 50% | 每个连续回测段起点 |
| 目标期末 SOC | 50% | 通过硬约束或显式惩罚实现 |
| 充电效率 | 95% | 单程 |
| 放电效率 | 95% | 单程 |
| 决策间隔 | 5 分钟 | 1/12 小时 |
| 优化 horizon | 60 分钟 | 12 步 |

20 kWh 按已确认口径表示 10%-90% SOC 安全窗口内的可用能量。为使能量方程与百分比 SOC 一致，基准模型使用 25 kWh 毛能量，因此 E_min = 2.5 kWh、E_max = 22.5 kWh，两者相差 20 kWh。市场备用下限高于安全下限时，安全下限只用于故障或明确的应急情景，不得被普通套利使用。

第一阶段明确假设额定功率之外的爬坡限制不构成约束。该假设进入配置，后续可增加爬坡敏感性。

## 场景

### S1：纯价格信号

- 不引入真实负荷与光伏；
- 进口和出口功率边界由基准资产和参数化 NMI 限制决定；
- 用于隔离概率预测对价格套利决策的贡献；
- 结果按资产和单位容量报告；
- 只能称为运营代理价值。

### S2：合成表后站点

- 使用固定随机种子或确定性规则生成负荷与光伏；
- 显式设置进口、出口和逆变器限制；
- 本地安全、备用和自用价值优先；
- 市场策略只能调用剩余功率与能量；
- 分别报告进口、出口、自用和电池能量流。

合成站点参数、生成规则和随机种子必须随实验保存。没有真实数据时不得将结果称为典型 NSW 用户收益。

## 符号与能量模型

定义：

- P_charge(t) >= 0：交流侧充电功率，kW；
- P_discharge(t) >= 0：交流侧放电功率，kW；
- E(t)：区间开始的电池能量，kWh；
- delta_t = 1/12 小时；
- eta_c、eta_d：充、放电单程效率。

SOC 连续性：

    E(t+1) = E(t)
             + eta_c * P_charge(t) * delta_t
             - P_discharge(t) / eta_d * delta_t

必须满足：

    0 <= P_charge(t) <= 10 kW
    0 <= P_discharge(t) <= 10 kW
    E_min <= E(t) <= E_max

普通市场运营还应满足备用 SOC 下限。禁止或施加足够强的约束避免同一时段同时充放电。

功率、能量和 SOC 的交流侧/直流侧口径必须在实现中保持一致。不得在充电和放电两端重复应用效率。

## 站点与 NMI 功率平衡

合成表后场景至少区分：

- site_load_kw：站点负荷；
- pv_generation_kw：表后光伏；
- battery_charge_kw；
- battery_discharge_kw；
- nmi_import_kw；
- nmi_export_kw。

采用一致的符号后满足站点功率平衡。实现可选择净功率表达，但必须通过行为测试证明：

- 光伏优先服务本地负荷；
- 电池充电来源被正确区分；
- 放电自用与净上网不重复；
- 同一 kWh 不同时计算避免购电收益和出口收入；
- 进口与出口不在同一 NMI 区间无解释地同时为正。

## 滚动决策

每个 model_issue_time：

1. 读取当时 SOC、站点状态、费用和未来 12 步概率预测；
2. 在未来 1 小时上求解充放电计划；
3. 只执行第一个五分钟动作；
4. 用实际发生的 RRP、负荷、光伏和执行结果更新状态；
5. 五分钟后使用新的预测重新优化。

不得一次性执行整个小时的历史最优计划。若优化失败、输入过期或约束不可行，应进入显式安全策略，例如不进行市场充放电并维持备用，而不是沿用旧计划或填零继续。

## 概率与风险

概率预测必须实际进入决策，而不只是报告。

允许的首期方式包括：

- 从经校准分位数构造有记录的离散情景；
- 使用模型直接生成的联合价格路径；
- 分位数或鲁棒目标；
- 期望价值减风险惩罚；
- 对损失使用 CVaR 或下行风险约束。

如果仅有 P10、P50、P90，不得无说明地把三点称为完整联合分布。情景概率、跨 horizon 相关性和尾部外推方法必须记录并做敏感性。

通用目标可表示为：

    最大化
        预期策略净价值
        - 风险权重 * 下行风险
        - 退化成本
        - 期末 SOC 偏差成本

风险权重为配置参数。期望收益更高但最坏情景显著恶化的策略必须单独报告。

## 结算模型

RRP 单位为 A$/MWh，用户能量价格统一换算为 A$/kWh：

    spot_price_aud_per_kwh = RRP / 1000

基础价格映射：

    import_price = spot_price_aud_per_kwh + import_adders
    export_price = spot_price_aud_per_kwh + export_adjustments

import_adders 和 export_adjustments 必须拆分为有方向、单位和来源的参数。可包含：

- 可变网络费；
- 零售商加价或折价；
- 市场与结算费用；
- 损耗调整；
- 平台或聚合服务费；
- 税费；
- 其他与策略相关的可变费用。

固定且在基线与策略间完全相同的费用可以从增量比较中抵消，但必须声明，不能因未建模而默认为零。

负 RRP 不得自动截断。负价是否传导到进口或出口由费用映射和合同假设决定。

## 费用情景

第一阶段至少维护：

### Gross-RRP

仅使用 RRP 的毛价值诊断，不包含费用。该结果不得称为净收益。

### Low-fee

低费用与低摩擦假设。

### Base-fee

有来源、可解释的中间假设。

### High-fee

较高网络、零售、平台或损耗成本假设。

具体数值在实现阶段依据公开 NSW 费率或明确研究假设冻结。每组情景必须记录：

- 数值；
- 单位；
- 正负方向；
- 是否作用于进口、出口、吞吐量或固定周期；
- 来源或假设依据；
- 截至日期。

不得选择最有利费用情景作为唯一主结论。

## 退化成本

没有真实电芯与保修数据时，退化采用参数化吞吐成本：

    degradation_cost
        = battery_energy_throughput_kwh
          * degradation_cost_aud_per_kwh

低、中、高退化成本与费用情景分别或组合做敏感性。吞吐量、等效完整循环和 SOC 分布必须同时报告。

## 比较策略

### C0：不进行市场响应

纯价格场景下电池保持初始或备用状态。合成站点下可对应无电池或不进行市场响应的反事实。

### C1：本地价值策略

仅服务光伏自用、备用或明确的本地规则，不响应 RRP。

### C2：规则型价格策略

使用训练期或滚动历史确定的阈值，在安全包络内充放电。

### C3：原始 P5MIN 滚动优化

使用最新可见 P5MIN 点预测执行确定性滚动优化。

### C4：P5MIN 概率校准策略

使用概率校准后的 P5MIN 进行风险感知滚动优化。

### C5：自研概率模型策略

使用候选模型的概率输出，其他资产、费用和求解配置与 C3、C4 相同。

### C6：完美预知上界

使用真实未来价格求解，但仍遵守全部物理和结算约束。只表示机会空间，不得作为可部署收益。

所有策略必须在相同实际价格版本、站点轨迹、初始 SOC、费用和约束下配对比较。

## 收益公式

通用策略净价值：

    策略净价值
        = 避免购电成本
        + 净上网收入
        - 充电购电成本
        - 可变网络与零售费用
        - 损耗成本
        - 退化成本
        - 平台与市场费用
        - 其他增量成本

增量净收益：

    增量净收益 = 候选策略净价值 - 反事实基线净价值

所有组成项按五分钟区间保留，不能只保存最终总数。

## 运营指标

至少报告：

- 毛价值与各费用后的净价值；
- 相对 C0-C5 的增量净收益；
- 月度、季度和年度收益；
- 最大回撤与亏损月份比例；
- 最差日、周、月和价格路径损失；
- 尖峰时段收益及其占比；
- 充电、放电和总吞吐量；
- 等效完整循环；
- SOC 分布和备用违反次数；
- 进口、出口、功率和能量越限；
- 同时充放电次数；
- 优化失败与安全回退次数；
- 相对完美预知上界捕获率；
- 概率模型造成的 false charge 和 false discharge 成本。

收益高度集中于少数尖峰时，应明确报告去除前若干尖峰后的结果。

## 敏感性

至少覆盖：

- 充放电效率；
- 额定与可用能量；
- 功率/能量比；
- 初始和期末 SOC；
- 备用 SOC；
- 进口与出口限制；
- 低、中、高费用；
- 退化成本；
- 概率校准误差；
- 风险权重；
- 尖峰捕获率；
- 通信或执行延迟的代理情景。

敏感性应使用预先定义的网格或场景，不得只展示最有利组合。

## 行为测试

实现前必须为以下行为编写测试：

- 10 kW 持续 5 分钟对应 10/12 kWh 交流侧能量；
- SOC 充放电效率只应用一次且方向正确；
- SOC 不越过安全和备用边界；
- 初始和期末 SOC 处理一致；
- 禁止同时充放电；
- 负价进口和高价出口符号正确；
- RRP 从 A$/MWh 正确转为 A$/kWh；
- import_adders 与 export_adjustments 方向正确；
- 自用和出口收益不重复；
- 每次滚动只执行第一步；
- 原始 P5MIN 与候选模型使用相同状态和费用；
- 完美预知仍遵守物理约束；
- 输入缺失、过期或不可行时触发安全策略。

## 结果边界

任何报告必须明确：

- 资产和站点为合成假设；
- 费用为参数化情景；
- 没有真实合同和执行数据；
- 价格影响忽略，资产被视为 price taker；
- 历史回测不保证未来收益；
- 模型价值只能在所用 NSW1 数据区间和情景中解释。
