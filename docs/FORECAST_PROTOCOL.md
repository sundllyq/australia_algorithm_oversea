# 概率预测与评价协议

## 目标

第一阶段任务是在每个五分钟 model issue time 输出未来 12 个 NSW1 RRP 区间的条件概率信息。概率预测是首要产品，点预测只是分布摘要和诊断。

模型必须回答的不只是“最可能的价格是多少”，还包括：

- 负价概率有多大；
- 高价或尖峰风险有多大；
- 预测区间是否校准；
- 不确定性是否随 horizon 和市场状态合理变化；
- 这些概率是否改善储能风险与收益。

## 预测输出契约

每个模型至少输出：

| 字段 | 要求 |
|---|---|
| model_issue_time_aest | 五分钟边界 |
| target_interval_end_aest | 目标 interval-ending |
| horizon_minutes | 5、10、...、60 |
| horizon_step | 1...12 |
| region_id | NSW1 |
| q10_aud_per_mwh | P10 |
| q50_aud_per_mwh | P50 |
| q90_aud_per_mwh | P90 |
| prob_negative | P(RRP < 0) |
| model_id | 模型与版本 |
| data_snapshot_id | 数据快照 |
| generated_at_utc | 产物生成时间 |

推荐同时输出：

- 条件均值；
- 更多尾部分位数，例如 P01、P05、P95、P99；
- 多个高价阈值的超越概率；
- 经校准的联合 12 步场景样本；
- 原始未校准输出和校准后输出。

所有分位数必须满足单调性。若模型产生分位数交叉，应通过有记录的方法修复，并同时报告交叉发生率。

## 预测对象

主目标为 NSW1、INTERVENTION=0 的五分钟实际 RRP，单位 A$/MWh。具体价格版本由数据快照声明。

模型可对价格做变换或分解，例如：

- P5MIN 加残差；
- 中心价格加尾部事件；
- 符号、状态与条件价格的两阶段模型；
- 稳健变换后的回归。

无论内部如何建模，主评价必须恢复到原始 A$/MWh 尺度，且不能隐藏负价或尖峰。

## P5MIN 的四重角色

### 官方点基线

原始 P5MIN RRP 是第一比较对象。所有模型必须在相同 issue、target、样本和信息集上报告相对差值。

### 概率校准基础

根据历史 P5MIN 误差构建条件分布。条件可包括 horizon、时段、月份、P5MIN 水平、近期波动和预测修订。

### 残差模型中心

定义：

    residual = actual NSW1 RRP - latest available P5MIN NSW1 RRP

模型预测 residual 的分位数或分布，再与 P5MIN 合成最终价格分布。

### 集成成员

P5MIN 可与独立模型、状态模型和其他概率模型组合。集成权重只能在训练或验证期确定。

## 必须实现的基线

### B0：最近实际价格

使用决策时最新可见的实际 NSW1 RRP 作为所有 horizon 的持久性预测。

### B1：季节性价格

使用相同五分钟时段的历史日内或周内统计量。统计量只能由训练期和决策时可见历史计算。

### B2：原始 P5MIN

使用每个 model issue time 最新可见且覆盖目标区间的 P5MIN。不能使用目标的最终一次 P5MIN。

### B3：简单 P5MIN 概率校准

按 horizon 建立经验残差分位数。这是概率预测的最小可验收基线。

### B4：简单事件基线

使用训练期按 horizon 和时段估计的负价及高价基础率，或由校准后的 P5MIN 分布计算事件概率。

## 模型研究顺序

### 阶段 1：P5MIN 概率校准

先验证最简单的条件残差分布、滚动窗口校准和分位数回归。目标是快速建立诚实的概率基线。

### 阶段 2：树模型残差预测

使用适合非线性和异质特征的分位数模型，比较不同 feature set 与 horizon 建模方式。

### 阶段 3：状态与尾部模型

研究负价、高价和普通状态的分类概率，以及状态条件下的价格分布。

### 阶段 4：直接多步与深度时序模型

只有在数据量、基线和评估流程稳定后才尝试。复杂模型必须证明其增量价值足以覆盖训练、推理和维护复杂度。

### 阶段 5：概率集成

基于验证期校准、pinball loss 或运营目标组合模型。不得在最终测试集调权。

## 特征组与数据链路

每个实验明确选择并编号以下特征组：

### F0：P5MIN

- 12 点价格曲线；
- 当前 horizon 的 P5MIN；
- 曲线斜率、极值、范围和形状；
- 同一目标在相邻 run 中的修订；
- 当前 run 与历史 run 的差异。

### F1：近期实际价格

- 仅使用决策时已发布的 NSW1 RRP 滞后；
- 滚动位置、波动、符号变化和尖峰距离；
- 所有窗口只向过去。

### F2：P5MIN 区域市场信息

- 决策时可见的区域需求、可用能力、可再生能源或其他 REGIONSOLUTION 字段；
- 字段必须经过 AEMO 数据模型核验和单独可见性审计。

### F3：其他市场数据

- 实际或预测需求；
- 发电与机组状态；
- 联络线流量和限制；
- 绑定约束及边际值；
- 其他 NEM 区域数据。

其他区域只能是辅助特征，并必须进行无该特征的消融。

### F4：日历

- NEM AEST 的分钟、小时、星期和月份；
- 新州工作日、周末和节假日；
- 周期编码不得使用目标之后的信息。

### F5：天气

天气不是第一阶段数据入口的前置条件。加入时必须保存 forecast vintage；事后实况天气不能冒充预测时可见天气。

每个模型结论必须通过特征组消融说明改善来自何处，不能只比较算法名称。

## 切分与滚动评价

- 禁止随机 train/test split。
- 最终测试期为最新完整 12 个月候选，数据审计后冻结。
- 测试期之前设置连续验证期。
- 训练采用 expanding 或明确长度的 rolling window。
- 重训频率、校准窗口和超参数更新频率写入配置。
- 任何标准化、缺失填补、阈值学习和特征选择仅在当次训练窗口拟合。
- 同一个 target 的多个 horizon 可同时存在，但 bootstrap 和显著性分析必须考虑时间及目标相关性。
- 最终测试集只用于一次主结论；探索性反复查看必须记录并降低结论强度。

## 概率指标

### Pinball loss

对分位数 tau 和预测 q_tau：

    L_tau(y, q) =
        tau * (y - q),       当 y >= q
        (1 - tau) * (q - y), 当 y < q

必须分 P10、P50、P90 和 horizon 报告，并与简单 P5MIN 残差分位数基线比较。

### 区间覆盖与宽度

对 P10-P90：

- 名义覆盖率为 80%；
- 报告实际覆盖率；
- 报告平均和分状态区间宽度；
- 同时观察过窄失准和过宽无信息。

### 完整分布指标

若模型输出足够分位数、参数分布或情景样本，报告适用的：

- CRPS；
- Weighted Interval Score；
- PIT 或 rank histogram；
- 联合 horizon 的场景覆盖和相关结构。

不得从 P10、P50、P90 三点无说明地声称拥有完整分布。

## 事件指标

固定负价事件：

    RRP < 0 A$/MWh

高价与尖峰阈值不在初始化阶段硬编码为唯一值。每个实验从配置读取一个或多个阈值，并说明其业务或统计依据。

至少报告：

- Brier score；
- 可靠性或校准曲线；
- 事件发生率；
- precision、recall 和 PR-AUC；
- false positive 与 false negative 的次数和价格成本；
- 按 horizon 的事件表现。

事件稀少时不得只报告 accuracy 或 ROC-AUC。

## 点预测诊断

P50 作为中位数点预测，模型提供均值时可另行报告。至少包括：

- MAE；
- RMSE；
- Bias；
- 分 horizon 误差；
- 绝对误差分位数；
- 负价、高价和普通状态下的误差。

RMSE 容易被少数尖峰主导，因此不得单独作为模型选择依据。

## 运营评价连接

每个进入候选集的概率模型都要向储能回测提供相同格式的 12 步概率输出。回测至少比较：

- 原始 P5MIN 驱动的滚动策略；
- P5MIN 概率校准策略；
- 自研概率模型策略；
- 规则型策略；
- 完美预知上界。

模型的综合结论包括：

- 相对预注册 P5MIN 概率校准基线的概率指标变化；
- P50 或其他点摘要相对原始 P5MIN 的点指标变化；
- 相对 P5MIN 策略的净价值变化；
- 风险、回撤和错误决策成本变化；
- 费用和资产敏感性下的稳定性。

预测指标改善但运营价值下降，应标记为“预测改进、决策未改进”，而不是整体成功。

## 不确定性与统计比较

- 对时间序列使用移动区块 bootstrap 或其他保留时间相关性的方法；
- 报告指标差值的区间，而不仅是单一均值；
- 对 horizon、月份和价格状态进行分层；
- 不因一次尖峰产生的偶然收益宣称稳定改善；
- 单个模型在多个指标中选择性胜出时报告全部预注册主指标。

## 主验收方式

本项目没有预设固定百分比门槛。每个候选模型按以下方式判定：

1. 是否在冻结的滚动测试集上相对预注册的 P5MIN 条件误差/校准基线改善主概率指标；
2. 覆盖率和区间宽度是否合理；
3. 负价与高价概率是否校准；
4. 改善是否跨多个 horizon 和月份存在；
5. 是否改善至少一个带费用情景下的储能净价值且未显著恶化风险；
6. 复杂度是否与增量价值相称。

若差异不确定，应结论为“未证明优于 P5MIN”，不得将无显著证据解释为等效或成功。

## 必备产物

- 逐 issue、target、horizon 的预测 Parquet；
- 原始与校准后概率输出；
- 分 horizon 指标；
- 校准、覆盖、事件和误差图；
- 概率指标相对 P5MIN 校准基线、点指标相对原始 P5MIN 的配对差值；
- 滚动训练与预测时间日志；
- 数据、特征、模型和配置 manifest；
- 使用 docs/EXPERIMENT_TEMPLATE.md 编写的实验记录。

## 泄漏检查

提交实验前逐项确认：

- P5MIN 是决策时最新可见版本，而不是目标最终版本；
- 实际价格滞后在当时已经发布；
- 天气若使用则为历史 forecast vintage；
- 价格修订和月度归档未进入历史信息集；
- 校准器未在测试期拟合；
- 阈值和特征未根据最终测试结果选择；
- 同一 target 的未来信息未通过曲线统计泄漏；
- 训练、验证和测试边界未被缓存或预处理跨越。
