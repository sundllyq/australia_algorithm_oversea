# 条件 ECC：从边际概率预测到可信的 NSW1 电价路径

> 本文由“解释条件 ECC”对话整理而成，保留通俗例子，并对术语、项目范围和算法细节做了统一。  
> 文档性质：离线研究说明，不代表真实市场报价、控制策略、结算结果或商业收益承诺。  
> 方法与文献核验日期：2026-08-19。

## 1. 先记住一句话

条件 ECC 可以先理解为：

> **概率模型负责预测每个未来时刻可能出现哪些价格；条件 ECC 再借用相似历史状态下的“联合排序骨架”，把这些分散的价格样本拼成一条条更像真实市场演化的未来路径。**

全篇最核心的转换链是：

```math
\boxed{
\text{固定 horizon 内的相对名次 }R
\rightarrow
\text{经验分位位置 }u
\rightarrow
\text{当前价格 }Q_{t,h}(u)
}
```

$R$ 回答“在同一列排第几”，$u$ 回答“位于当前边际分布的什么位置”，$Q_{t,h}(u)$ 才回答“这个位置今天是多少钱”。整条场景的概率权重另记为 $w$，不能与 $u$ 混为一谈。

如果把未来电价场景生成比作拍电影：

- 分位数模型和逆 CDF 负责准备“演员”，即每个时刻可能出现的价格及其概率；
- 历史残差模板负责提供“剧本”，即价格怎样连续变化、尖峰怎样开始和结束；
- “条件”表示不从历史剧本库中随便抽一本，而是优先选择与当前市场状态相似的剧本；
- ECC 式重排负责让今天的“演员”按照这些历史剧本组合起来。

最终得到的不是单一价格预测，而是一组完整的未来价格路径，可供风险感知的储能滚动决策使用。

## 2. 本项目中的范围

本文所有实现建议都服从项目第一阶段契约：

| 项目 | 第一阶段定义 |
|---|---|
| 预测目标 | 仅 NSW1 区域参考价格（Regional Reference Price, RRP） |
| 决策频率 | 每 5 分钟一次 |
| 预测范围 | 未来 60 分钟 |
| 预测步 | $h=1,\ldots,12$，对应 $t+5$ 至 $t+60$ 分钟 |
| 时间语义 | AEST（UTC+10），5 分钟 interval-ending |
| 最小概率输出 | P10、P50、P90，并保留扩展更多分位数或场景的接口 |
| 核心外部预测 | AEMO P5MIN |
| 最终用途 | 离线储能滚动回测；每次只执行当前第一步的模拟动作 |

原对话使用过“两小时、24 步”和 NSW/QLD/VIC 联合预测来帮助解释概念。它们在本文中只作为扩展思路，不是第一阶段验收范围。其他 NEM 区域只能作为决策时已知的辅助特征；使用时必须证明可见性、做消融实验，且标签、回测与结算价格仍然只属于 NSW1。

核心领域结构也不应把 12 步写死。当前配置为 12 步，未来可通过配置扩展更长 horizon。

## 3. 为什么只有 P10、P50、P90 还不等于一条未来路径

假设要预测 NSW1 接下来的三个 5 分钟区间。概率模型分别告诉我们：

| 目标区间 | 单独看时的价格分布 |
|---|---|
| 10:05 | 大多数在 50–80 A$/MWh，偶尔到 300 |
| 10:10 | 大多数在 55–90 A$/MWh，偶尔到 400 |
| 10:15 | 大多数在 60–100 A$/MWh，偶尔到 500 |

每一列单独看都可能很合理。但如果从三个分布中完全独立抽样，可能得到：

```text
60 → 400 → 65
```

三个数各自都来自合法的概率分布，组合起来却可能缺少真实电力市场中的事件连续性。一次尖峰往往会受到供需、约束和联络线状态的共同影响，并可能持续多个 dispatch interval。较自然的场景可能是：

```text
120 → 400 → 180
```

这说明概率预测需要回答两个不同的问题：

1. **边际问题**：每个未来时刻自己的价格分布是什么？
2. **联合问题**：不同未来时刻的价格应当怎样一起高、一起低，或者先升后降？

分位数模型、CDF 与 ECC 分别负责不同部分，不能互相替代。

## 4. 三个核心概念

### 4.1 边际分布：每个格子里有哪些价格

对某个 horizon，例如 NSW1 的 $t+30$ 分钟，模型可以输出：

```text
P10 = 40
P50 = 70
P90 = 180
P99 = 3000
```

这些分位数描述的是这一个目标区间自己的不确定性，称为边际分布（marginal distribution）。

在本项目中，更自然的首版做法是以当时可用的 P5MIN 为锚点，预测残差的条件分布：

```math
E_{t,h}=Y_{t+h}-A_{t,h},
```

其中：

- $A_{t,h}$ 是决策时点 $t$ 可用的 P5MIN vintage 对目标区间 $t+h$ 的预测；
- $Y_{t+h}$ 是后来才观测到的 NSW1 实际 RRP；
- $E_{t,h}$ 是 P5MIN 的预测残差。

模型先预测 $E_{t,h}$ 的分位数，再与 $A_{t,h}$ 相加，得到最终价格分布。这样既保留 AEMO 预测信息，也让模型集中学习条件误差与尾部风险。

### 4.2 CDF 与逆 CDF：把几个分位点补成可采样的分布

累积分布函数（Cumulative Distribution Function, CDF）定义为：

```math
F_h(x)=P(X_h\le x).
```

分位数函数是它的广义反函数：

```math
Q_h(u)=F_h^{-1}(u),\qquad 0<u<1.
```

更严格地说，广义分位数函数可以写成：

```math
Q_h(u)=\inf\{x:F_h(x)\ge u\}.
```

这里的 $u$ 是**累计概率坐标**。在预测分布已经校准且近似连续时，$Q_h(0.7)$ 可以通俗地称为 P70：预测分布中约 70% 的概率质量位于这个价格阈值及其以下。它不是说“价格恰好等于 $Q_h(0.7)$ 的概率为 70%”，也不是说某一条取到 P70 的场景有 70% 的发生概率。前者描述分布中的位置，单条场景的概率权重则是另一个量。

分位数模型给出的 P10、P50、P90，本质上是逆 CDF 上的几个离散点。要生成大量场景，就还需要回答：

> P37.2、P83.6 或 P96.7 分别对应多少价格？

因此工程中常说的“CDF 插值”，在采样阶段通常更准确地指：

> 根据离散分位点构造单调的分位数函数，再用 $Q_h(u)=F_h^{-1}(u)$ 采样。

例如抽到 $u=0.73$，便计算：

```math
x_h=Q_h(0.73).
```

如果插值得到 P73 为 96 A$/MWh，这次边际采样结果就是 96 A$/MWh。

这里有三个不能忽略的问题：

- 独立训练的分位数可能交叉，必须先保证 $Q_h(u)$ 随 $u$ 非递减；
- P10、P50、P90 满足第一阶段最小输出要求，但通常不足以稳定描述 NEM 电价的负价与尖峰尾部；
- P90 到 P99 之间不能未经验证就做简单线性外推，尾部处理会直接改变场景中的尖峰概率和强度。

所以，CDF/逆 CDF 是成熟的概率工具，但“由哪些分位点构造、怎样校准、怎样处理尾部”仍是需要用时间外数据验证的建模选择。

### 4.3 依赖结构：这些价格怎样一起出现

Copula 关注的不是每个变量本身的数值分布，而是它们如何一起变化。

生活中的例子是：气温有自己的分布，冰淇淋销量也有自己的分布；“气温较高时销量通常也较高”描述的就是依赖关系。

放到 NSW1 电价中，依赖结构回答的是：

- $t+10$ 分钟出现尖峰时，$t+5$ 和 $t+15$ 分钟通常处于什么相对位置？
- 尖峰通常只持续一个区间，还是连续多个区间？
- 高价事件结束时，是快速回落还是逐步恢复？

可以把整个关系记为：

```math
\boxed{
\text{边际分布}
+
\text{Copula / 依赖结构}
=
\text{联合分布}
}
```

## 5. ECC 到底做了什么

ECC 是 Ensemble Copula Coupling 的缩写，可以先把它理解成一种**联合场景拼接方法**。它不是另一个价格预测模型，而是位于“各 horizon 的边际概率预测”和“完整路径场景”之间的后处理步骤。

在 ECC 开始之前，模型已经分别回答了：

> 未来第 1、2、……、$H$ 个 horizon 各自可能出现哪些价格，以及这些价格各有多高或多低的概率。

但这些答案仍然是 $H$ 个分开的价格分布。ECC 进一步回答：

> 第 1 个 horizon 的某个低位或高位样本，应当与后续各 horizon 的哪些样本放在同一行，才能组成一条具有经验依赖关系的未来路径？

从全局看，它接收两类输入并产生一种输出：

| 角色 | 内容 | 决定什么 |
|---|---|---|
| 输入 A：当前边际分布 | 每个 horizon 当前可能出现的价格样本 | 每一列有哪些价格 |
| 输入 B：联合秩模板 | 不同 horizon 的高低位置怎样跨列连接 | 哪些价格应属于同一条路径 |
| 输出：联合场景 | 每行包含未来全部 horizon 的价格 | 一组可送入滚动优化的完整路径 |

可以把每个 horizon 想成一盒已经从低到高排好的价格卡片。ECC 不增加、删除或改写任何一盒中的卡片，只按照一份联合秩模板，从每盒各取一张并把它们串成一条路径；每张卡在这一轮重排中只使用一次，直到拼出全部路径：

```text
各 horizon 的校准边际样本
            +
表达跨 horizon 依赖的联合秩模板
            ↓
          ECC 重排
            ↓
未来 H 个 horizon 的多条联合价格场景
```

因此，ECC 的核心性质是：**在纯重排步骤中保持每个 horizon 的边际样本集合不变，同时为样本之间加入经验依赖关系**。它不会自动修复错误的 P10、P50、P90 或尾部概率；如果边际分布或秩模板有问题，最终场景仍然会有问题。

经典 ECC 通常从当前原始 ensemble forecast 取得联合秩模板；本项目则准备从相似历史决策时点之后的 P5MIN 残差路径提取模板。因此，本文所称的“条件 ECC”更接近条件经验 Copula 或 SimSchaake 风格的场景耦合，第 7 章会进一步区分这些术语。

在这个全局框架下，ECC 的具体动作是：

1. 从每个校准后的边际分布取得一组样本；
2. 保留每个 horizon 的样本集合不变；
3. 根据一个已有联合样本的秩结构，对各列样本重新排列；
4. 将排列后同一行的值视为一条完整场景。

### 5.1 先把“秩结构”说清楚

先不考虑 ECC。“秩”（rank）就是一个数在一组数从低到高排列后所处的**名次**。本文约定最小值的秩为 1，最大值的秩为样本数量 $M$。

例如有三个成员：

| 成员 | 原始数值 | 从低到高的秩 |
|---|---:|---:|
| A | 20 | 1 |
| B | 80 | 3 |
| C | 50 | 2 |

因为排序结果是 $20<50<80$，所以 A、B、C 的秩分别是 1、3、2。这里要区分：

- **排序**是把数值排成 $20,50,80$；
- **秩**是把名次写回原成员，得到 A 为 1、B 为 3、C 为 2。

秩只保留“谁比谁高”的相对顺序，不保留相差多少。即使数值变成 200、8000、500，A、B、C 的秩仍然是 1、3、2。因此，两组绝对水平差异很大的数据可以拥有完全相同的秩。

在本文中，几个相关概念可以按下面的顺序理解：

```text
一个数在一列中的名次
    → 秩
同一个历史成员跨多个 horizon 的名次组合
    → 秩向量
全部历史成员的秩向量放在一起
    → 秩矩阵
秩矩阵中“同一成员怎样跨 horizon 连接”的整体模式
    → 联合秩结构
```

后文还会出现“秩相关”（rank correlation）。它只是用一个数概括两列排名是否相似：两列顺序越一致，秩相关越接近 1；顺序越相反，越接近 -1；没有稳定关系时接近 0。秩相关是对依赖关系的简化摘要，完整的联合秩结构包含的信息更多。

把这个概念放回本项目。假设已经选出 $M$ 个相似历史决策时点，每个历史时点都提供一条随后 $H$ 个 horizon 的残差路径，把它们写成矩阵：

```math
E=(e_{m,h}),\qquad m=1,\ldots,M,\quad h=1,\ldots,H.
```

其中：

- 每一行 $m$ 是一个历史模板成员，也就是从一个历史决策时点出发的完整残差路径；
- 每一列 $h$ 是同一个相对预测步，例如所有历史成员各自的 $t+15$ 分钟残差。

对固定的 horizon $h$，将这一列的 $M$ 个残差从低到高排名，得到：

```math
R_{m,h}
=
\operatorname{rank}\!\left(
e_{m,h};e_{1,h},\ldots,e_{M,h}
\right).
```

没有并列值时，每列的秩恰好是 $1,2,\ldots,M$ 的一个排列。成员 $m$ 跨全部 horizon 的秩向量

```math
(R_{m,1},R_{m,2},\ldots,R_{m,H})
```

描述该成员在不同 horizon 分别处于历史模板池的什么相对位置；所有成员组成的 $M\times H$ 秩矩阵 $R$，就是这里所说的**联合秩结构**。同一行的成员身份必须保留，正是这种跨列连接表达了经验依赖关系。

> **排名是在每个 horizon 内跨历史成员进行的，不是在一条路径内部把不同时点互相排名。**

为了避免把几种“顺序”混在一起，可以把本文出现的顺序分成三类：

| 顺序 | 比较对象 | 在 ECC 中的作用 |
|---|---|---|
| 列内相对顺序 | 固定 $h$，比较 $e_{1,h},\ldots,e_{M,h}$ | 真正计算 $R_{m,h}$ 的地方，决定同一 horizon 上谁取得较低或较高的当前边际价格 |
| 一行中的分位位置轨迹 | 固定成员 $m$，连接 $R_{m,1},\ldots,R_{m,H}$ | 描述这个成员跨 horizon 的相对高低位置如何变化，但不是把一行中的价格重新排名 |
| 不同历史日期的绝对价格顺序 | 比较不同 anchor 后实际发生的 RRP | 由于各日期的预测基准不同，不能直接当作今天的分位顺序，本项目不把它直接移植到当前价格分布 |

因此，后文所说的“保持价格顺序”，如果没有额外说明，严格含义都是：**在同一个 horizon 内，模板成员之间的残差相对顺序，被映射为当前场景价格的相对顺序。**它不是说一条路径从 $t+5$ 到 $t+60$ 的价格升降次序必须复制历史。

### 5.2 从历史残差到今天场景：一个完整五样本例子

先假设选出了五个相似历史决策时点 A–E。每一行是从该历史时点出发、随后三个 horizon 的 P5MIN 预测残差，即实际 RRP 减去该历史决策时点可用的 P5MIN。下表数值仅用于解释算法，不代表真实 NSW1 样本：

| 历史模板成员 | $h=1$（+5 分钟） | $h=2$（+10 分钟） | $h=3$（+15 分钟） |
|---|---:|---:|---:|
| A | -30 | -10 | -50 |
| B | -10 | -30 | -20 |
| C | 5 | 20 | 10 |
| D | 40 | 500 | 700 |
| E | 120 | 150 | 180 |

现在逐列排名。例如在 $h=2$ 这一列，B 的 -30 最低，所以秩为 1；A 的 -10 次低，所以秩为 2；D 的 500 最高，所以秩为 5。三列分别排名后得到：

| 历史模板成员 | $h=1$ 的秩 | $h=2$ 的秩 | $h=3$ 的秩 |
|---|---:|---:|---:|
| A | 1 | 2 | 1 |
| B | 2 | 1 | 2 |
| C | 3 | 3 | 3 |
| D | 4 | 5 | 5 |
| E | 5 | 4 | 4 |

为什么残差的列内顺序可以对应价格的列内顺序？先只看当前决策时点的某一个固定 horizon。若所有候选场景共享同一个基准预测 $\widehat p_h$，则候选价格可以写成：

```math
p_{m,h}=\widehat p_h+\varepsilon_{m,h}.
```

对任意两个场景 A、B：

```math
\varepsilon_{A,h}<\varepsilon_{B,h}
\quad\Longrightarrow\quad
\widehat p_h+\varepsilon_{A,h}
<
\widehat p_h+\varepsilon_{B,h}.
```

所有场景都加上同一个 $\widehat p_h$，排序不会改变。这解释了在**同一个当前预测目标**上，为什么“更负或更小的 surprise”应对应较低的场景价格，“更正或更大的 surprise”应对应较高的场景价格。

但历史模板来自不同 anchor。第 $m$ 个历史成员满足 $y_{m,h}=a_{m,h}+e_{m,h}$，其中历史 P5MIN 基准 $a_{m,h}$ 通常各不相同，所以跨历史日期一般不能推出：

```math
\operatorname{rank}(e_{m,h})
=
\operatorname{rank}(y_{m,h}).
```

本方法也不是把某个历史残差直接加到今天的 P5MIN 上。它只把历史残差在相似模板池中的**相对名次**当作今天 surprise 的经验位置，再交给今天自己的边际分布决定价格数值。实际重排中的顺序保证来自两个单调步骤：秩越高则 $u$ 越大，而分位数函数 $Q_h(u)$ 随 $u$ 非递减。

这里不只要看每列有哪些名次，还要保留同一行怎样跨列连接。例如 D 的秩向量是 $(4,5,5)$：在这个模板池中，它的第一步残差较高，后两步都最高。E 的秩向量是 $(5,4,4)$：第一步最高，后两步仍较高但相对位置下降。五行秩向量合在一起，才构成完整的联合秩结构。

再假设当前决策时点是 10:00，三个未来 horizon 各有五个从当前校准边际分布取得、并按从小到大排序的价格样本：

| 顺序 | 10:05 | 10:10 | 10:15 |
|---|---:|---:|---:|
| 1 | 40 | 45 | 50 |
| 2 | 50 | 60 | 65 |
| 3 | 60 | 80 | 90 |
| 4 | 80 | 150 | 180 |
| 5 | 120 | 500 | 700 |

按照历史秩矩阵为每个成员逐列取值。例如 D 的秩向量是 $(4,5,5)$，所以分别取 10:05 的第 4 小样本、10:10 的第 5 小样本和 10:15 的第 5 小样本，得到路径 $80\rightarrow500\rightarrow700$。完整重排结果为：

| 新场景 | 10:05 | 10:10 | 10:15 |
|---|---:|---:|---:|
| A | 40 | 60 | 50 |
| B | 50 | 45 | 65 |
| C | 60 | 80 | 90 |
| D | 80 | 500 | 700 |
| E | 120 | 150 | 180 |

最关键的性质是：

> **ECC 没有改变任何一列里有哪些价格，只改变了不同列的哪些价格属于同一条路径。**

例如 10:10 在重排前后始终是：

```text
45、60、80、150、500
```

因此，重排原则上保留每个 horizon 的边际样本分布，同时为整条路径加入经验依赖结构。上述例子没有并列值；真实模板出现并列值时，必须使用显式且可复现的并列值处理规则（tie-breaking），使每列得到一一对应的排列。

### 5.3 为什么还要把“第几名”转换成“分布位置”

在上面的五样本例子中，秩向量 $(4,5,5)$ 可以直接理解为“分别取第 4、第 5、第 5 个已排序样本”。如果当前每个边际分布已经表示成五个这样的样本，到这里就足够了，**不必再做归一化**。

但逆 CDF，也就是分位数函数 $Q_h(u)$，不接受“第 4 名”这样的输入，只接受 0 到 1 之间的分位位置 $u$。因此需要做一次格式转换：

```text
第几名 R
    → 0～1 之间的分位位置 u
    → 分位数函数能够读取的输入 Q_h(u)
```

一种常用的转换约定是：

```math
u_{m,h}=\frac{R_{m,h}-0.5}{M}.
```

当 $M=5$ 时，可以把 0 到 1 分成五个等宽区间，并用每个区间的中点代表相应名次：

| 秩 $R$ | 代表的分位区间 | 中点 $u$ | 通俗位置 |
|---:|---:|---:|---|
| 1 | 0.0–0.2 | 0.1 | 低位 |
| 2 | 0.2–0.4 | 0.3 | 偏低 |
| 3 | 0.4–0.6 | 0.5 | 中间 |
| 4 | 0.6–0.8 | 0.7 | 偏高 |
| 5 | 0.8–1.0 | 0.9 | 高位 |

所以：

```math
(4,5,5)
\quad\longrightarrow\quad
\left(
\frac{4-0.5}{5},
\frac{5-0.5}{5},
\frac{5-0.5}{5}
\right)
=
(0.7,0.9,0.9).
```

这三个小数的含义分别是：

- 第一个 horizon 使用当前边际分布的 P70 位置，即 $Q_1(0.7)$；
- 第二个 horizon 使用当前边际分布的 P90 位置，即 $Q_2(0.9)$；
- 第三个 horizon 也使用当前边际分布的 P90 位置，即 $Q_3(0.9)$。

$u=0.7$ 使用的是概率刻度，但它不是“这个价格有 70% 的概率发生”，也不是价格等于 0.7 或模型有 70% 的置信度。它只是告诉分位数函数：到当前分布的 P70 位置取值。

这里尤其需要区分四个量：

| 量 | 回答的问题 | 不能误解成什么 |
|---|---|---|
| 秩 $R_{m,h}$ | 成员 $m$ 在第 $h$ 列排第几？ | 历史价格、概率或场景权重 |
| 分位位置 $u_{m,h}$ | 该名次在 0–1 概率刻度上位于哪里？ | 该场景发生的概率 |
| 当前价格 $Q_h(u_{m,h})$ | 今天第 $h$ 个边际分布在这个位置是多少钱？ | 历史残差数值的复制 |
| 场景权重 $w_m$ | 优化或统计汇总时给整条场景多少概率质量？ | 分位位置 $u_{m,h}$ |

例如 $M=5$ 且场景等权时，每一行的权重是 $w_m=1/5=20\%$。最高秩映射到 $u=0.9$，只表示它取得当前边际分布的 P90 位置，**并不表示这条场景有 90% 的发生概率**。若模板保留不等权权重，则必须明确采用加权经验 CDF，或者先按权重重采样为等权成员；不能一边使用简单等权秩公式，一边把不等权概率质量静默忽略。

公式中的 $-0.5$ 表示取每个区间的中点。这样既不会把最高名次映射到 $u=1$，也不会把最低名次映射到 $u=0$，从而避开逆 CDF 的两个端点。也可以采用其他归一化约定；这不是 ECC 的核心动作，但训练、场景生成和评价阶段必须使用同一约定。

将所有归一化秩写成矩阵 $U=(u_{m,h})$，就得到经验 Copula 模板的一种表示。它保留的是分位位置跨 horizon 的组合关系，不是历史残差的绝对数值。

### 5.4 “秩结构”不是复制历史价格，也不是路径内排序

假设某个历史模板成员跨五个 horizon 的秩向量是：

```text
1 → 3 → 5 → 4 → 2
```

它可以通俗描述为：

```text
相对较低 → 居中 → 最高 → 较高 → 相对回落
```

这里的“较低”或“最高”，始终是指该成员与**同一 horizon 的其他历史模板成员**相比所处的位置，而不是将这条路径自身五个时点的原始残差互相比较。

ECC 式方法把这些秩映射到今天各 horizon 的边际分布。若当前第 $h$ 个 horizon 的分位数函数为 $Q_h$，可写成：

```math
x_{m,h}=Q_h(u_{m,h}).
```

因此两部分各自负责：

```text
历史模板：跨 horizon 的分位位置组合 / 经验依赖骨架
当前概率预测：每个 horizon 的价格水平、离散程度和尾部概率
```

同一套历史秩结构在不同日期、不同 P5MIN 锚点和不同边际分布下，可以映射成完全不同的实际价格路径。反过来，秩从高位下降也不保证原始价格一定下降，因为不同 horizon 的边际价格尺度可能不同。“路径形状”只是便于交流的简称，更准确的说法是**跨 horizon 的边际分位位置轨迹**。

例如某成员前两步的分位位置从 P90 降到 P70，但当前边际分布可能满足：

```math
Q_1(0.9)=120,\qquad Q_2(0.7)=400.
```

此时分位位置下降，实际价格却从 120 上升到 400 A$/MWh。相反，在同一个固定 horizon 内，如果成员 A 的秩低于成员 B，则由于 $R\mapsto u$ 递增且 $Q_h$ 非递减，必有：

```math
R_{A,h}<R_{B,h}
\quad\Longrightarrow\quad
x_{A,h}\le x_{B,h}.
```

这里写作 $\le$ 而不是严格小于，是因为离散价格、分位数平坦段或并列值可能让不同概率位置映射到相同价格。由此可以准确地区分：ECC 保证的是**固定 horizon 上跨场景的单调相对顺序**，不是跨 horizon 的绝对价格升降顺序。

## 6. 为什么前面要加“条件”

如果不加条件，历史模板可能来自与当前完全不同的市场状态。例如当前是夏季工作日傍晚、需求高、reserve 紧张、价格正在上升，却拿冬季凌晨、低需求、联络线宽松时的秩结构来拼接场景。数学上可以重排，经济含义却很弱。

“条件”的含义是：

> 在预测起点 $t_0$，只用当时已经可见的信息寻找市场状态相似的历史决策时点，再使用这些历史时点之后实际发生的残差路径作为秩模板。

注意必须把“选择条件”和“模板结果”分开：

- 选择历史模板时，只允许使用历史决策 cutoff 当时已经可见的状态；
- 选中历史 anchor 后，可以读取它随后真实发生的价格或残差，用作模板内容；
- 绝不能用当前预测时点尚未发生的未来价格判断“今天和哪个历史时刻相似”。

否则就会产生 look-ahead leakage，回测结果会虚高。

## 7. 术语上的准确说法

原对话和项目方案使用“条件 ECC”作为便于交流的简称。严格区分时：

| 方法 | 秩模板通常来自哪里 |
|---|---|
| 经典 ECC | 当前原始 ensemble forecast 自身的联合秩结构 |
| Schaake Shuffle | 历史真实观测路径 |
| SimSchaake | 根据当前状态或预测相似度挑选的历史观测路径 |
| 本项目所谓“条件 ECC” | 相似历史决策时点之后的 P5MIN 预测残差路径 |

因此，本项目方法在技术上更接近：

> **Similarity-conditioned empirical copula / SimSchaake-style scenario coupling**  
> **基于相似历史状态的经验 Copula 联合场景重构**

继续使用“条件 ECC”并无不可，但实现文档和实验报告应说明模板来源，避免让读者误以为使用的是经典 ECC 的原始 ensemble 秩。

## 8. 相似历史路径到底怎样选

相似历史路径的核心不是找一条“未来价格看起来像今天”的曲线，而是：

> 找过去那些在决策 cutoff 时市场状态与当前相似的 anchor，再取这些 anchor 之后真实发生的残差向量。

建议使用“硬过滤 + 候选集内加权距离”两层选择。

### 8.1 第一层：按市场状态硬过滤

先排除明显不属于同一 regime 的历史数据，例如：

| 条件 | 示例 |
|---|---|
| 时段 | 傍晚状态优先匹配相近时段 |
| 季节 | 同季节或相邻月份 |
| 日期类型 | 工作日与工作日、周末与周末优先匹配 |
| 市场状态 | intervention、suspension 等状态不得与正常状态静默混用 |
| 约束状态 | 重要 constraint binding 与非 binding 尽量分开 |
| 联络线状态 | 拥塞、接近拥塞与宽松状态尽量分开 |
| 风险阶段 | Normal、Rising/Tightening、Spike、Recovery 分层 |

先过滤的原因是，单纯数值距离可能把一个冬季凌晨时刻判为“很近”，但其市场机制和经济含义与夏季傍晚并不相同。

### 8.2 第二层：在候选集中计算相似度

定义决策时点的状态向量：

```math
z_t=[
\text{recent price path},
\text{P5MIN level/revision},
\text{demand},
\text{wind/solar},
\text{reserve proxy},
\text{interconnector},
\text{constraint},
\text{calendar},\ldots].
```

当前时点 $t$ 与历史时点 $s$ 的加权距离可写成：

```math
D(t,s)=\sum_j w_j d_j(t,s),
```

其中 $d_j$ 是第 $j$ 个特征的差异，$w_j$ 是其权重。距离越小，历史状态越像当前状态。

第一阶段可考虑的特征包括：

| 类别 | 候选特征 | 主要作用 |
|---|---|---|
| 当前价格状态 | 最近可见 NSW1 RRP、P5MIN 曲线、P5MIN revision | 判断当前价格 regime 与官方预测变化 |
| 最近价格路径 | 最近 15/30/60 分钟 RRP、斜率、最大值、ramp | 区分进入尖峰与尖峰恢复 |
| 需求 | 当前需求、需求预测及 revision | 描述供需紧张程度 |
| 供给 | 风电、光伏、可调度供给的可见代理 | 描述供给与新能源状态 |
| 备用 | reserve 或 available generation 的可见代理 | 描述尖峰风险 |
| 联络线 | flow、limit、headroom | 描述 NSW1 与相邻区域是否可能脱钩 |
| 约束 | binding 状态、可见的边际值或分类 | 描述物理瓶颈 |
| 时间 | 时刻、星期、月份或季节 | 提供市场结构先验 |
| 周边区域 | 决策时已知的 QLD1/VIC1 状态 | 只作辅助特征，需证明可见性并做消融 |

### 8.3 为什么最近价格路径很重要

同样的当前价格可能处于完全不同的事件阶段：

```text
50 → 55 → 70 → 120 → 200    正在进入尖峰
```

```text
5000 → 2000 → 800 → 400 → 200    尖峰正在恢复
```

两种情况下当前 RRP 都是 200 A$/MWh，但未来 60 分钟的条件分布可能完全不同。因此不能只用当前价格匹配历史状态。

一个透明的研究 V1 可以把事件阶段粗分为：

```text
Normal → Rising/Tightening → Spike → Recovery
```

分类规则、阈值和状态转移必须只在训练与验证期确定，并进入配置和敏感性分析。

### 8.4 不同量纲必须先处理

价格差 3000 A$/MWh、需求差 500 MW 和 reserve 差 300 MW 不能直接相加。连续特征可以使用训练期统计量做稳健标准化：

```math
z_j=\frac{x_j-\operatorname{median}(x_j)}{\operatorname{IQR}(x_j)}.
```

NEM 电价同时存在负值和长尾，可在相似度特征中考虑：

```math
x'=\operatorname{asinh}(x/c),
```

或训练期 percentile/rank transformation，避免少数极端值完全支配距离。这里的变换只服务于匹配和建模；主评价与结算仍必须回到原始 A$/MWh 尺度，不能裁剪或隐藏极端价格。

### 8.5 相似模板不必等概率

对候选模板可按距离分配权重：

```math
\pi_s=
\frac{\exp(-D_s/\tau)}
{\sum_k\exp(-D_k/\tau)}.
```

含义很直观：特别像当前状态的历史模板多使用一些，勉强相似的少使用一些。温度参数 $\tau$、最近邻数量 $K$、特征权重和硬过滤规则都不是天然正确的常数，必须在时间顺序验证集上选择，并做稳定性和运营价值检验。

## 9. 为什么优先使用历史残差路径

假设某个历史时点的 P5MIN 预测和实际价格分别为：

```text
预测：60 → 65 → 70 → 75
实际：70 → 100 → 500 → 300
残差：+10 → +35 → +430 → +225
```

残差路径更直接地描述：

> 官方锚点没有预测到的冲击如何在不同 horizon 上持续和传播。

这通常比直接复用历史绝对价格更合适，因为不同年份中相同的 300 A$/MWh 未必处于相同市场背景。条件 ECC 真正需要的主要是残差之间的联合秩，而不是历史绝对价格本身。

这里仍需严格保存 forecast vintage。对历史 cutoff $s$，必须使用当时已经可用的 P5MIN 版本计算：

```math
e_{s,h}=y_{s+h}-a_{s,h}.
```

如果改用后来更新的 P5MIN 或目标区间最后一次预测，就会破坏真实信息集。

### 9.1 残差顺序不等于历史绝对价格顺序

考虑两个历史决策时点：

| 历史时点 | 当时预测 | 后来实际 | 残差 |
|---|---:|---:|---:|
| A | 50 | 500 | +450 |
| B | 1000 | 1100 | +100 |

如果只看历史实际价格，B 的 1100 高于 A 的 500；但从预测 surprise 看，A 从 50 跳到 500，是比 B 从 1000 到 1100 更强的未预见正向冲击。因此残差顺序为 A 高于 B，与绝对价格顺序相反。

条件 ECC 希望迁移的是：在已经利用 P5MIN、需求、reserve、constraint 等决策时可见信息后，剩余未知冲击如何共同演化。历史实际价格中还混合了当时已经被预测到的市场水平，所以不能把历史实际价格的 rank 直接称为今天的价格分位数。历史残差 rank 更准确的含义是：**在所选相似状态样本池中，这次 surprise 处于什么经验相对位置。**

### 9.2 异方差下，raw residual rank 也不自动等于条件分位位置

即使使用残差，也还有一个重要前提：选中的历史模板必须在条件误差尺度上足够可比。NEM 电价具有明显异方差。例如 $+500$ A$/MWh 的误差在正常市场可能极端，在已经进入数千元尖峰的状态下却可能并不罕见。条件筛选可以缓解这种问题，但不能自动消除它。

因此研究中至少应比较三种模板坐标：

1. raw residual 的列内经验 rank；
2. 用训练期条件尺度估计得到的 standardized residual rank；
3. 历史概率预测下的 PIT（Probability Integral Transform）位置。

若历史决策时点 $s$ 当时可用的预测 CDF 为 $F^{\mathrm{forecast}}_{s,h}$，后来实际价格为 $y_{s+h}$，则 PIT 坐标为：

```math
v_{s,h}=F^{\mathrm{forecast}}_{s,h}(y_{s+h}).
```

例如 $v_{s,h}=0.97$ 表示实际结果落在当时预测分布约 P97 的位置。它比“残差为 +800 A$/MWh”更直接地表达相对于当时预测尺度的 surprise 强弱。如果项目能够为历史 cutoff 重建经过校准的完整 CDF，PIT 路径应作为 raw residual rank 的重点对照方案；但 PIT 的质量同样依赖历史 CDF 的分位数单调性、校准和尾部估计，不能把一个失准 CDF 产生的 PIT 当成真概率。

## 10. 项目中的完整研究链路

### 10.1 从边际样本到联合场景

在阅读下面的链路前，需要先区分“边际样本”和“场景”。在决策时点 $t$，第 $h$ 个 horizon 的校准边际分布只描述一个目标区间的价格不确定性。记它的逆 CDF 为 $Q_{t,h}(u)$，从该边际取得一个分位位置 $u_{s,h}$ 后，生成的

```math
x_{s,h}=Q_{t,h}(u_{s,h})
```

只是第 $h$ 个目标区间的一个可能价格，尚不是一条未来路径。$u_{s,h}$ 可以来自等间隔分位网格、随机均匀抽样或经过验证的分层抽样；无论采用哪种方法，都必须沿用同一套单调化、校准和尾部规则。

“从每个边际生成 $S$ 个样本”的意思是：对未来每一个 horizon，分别准备 $S$ 个可能价格。当前 $H=12$，因此这一步一共产生 $12S$ 个**单点价格样本**。例如只看三个 horizon，且 $S=5$，可能得到三盒价格卡片：

```text
10:05：40、50、60、80、120
10:10：45、60、80、150、500
10:15：50、65、90、180、700
```

此时不同盒子中相同的样本序号没有天然的跨时间含义，不能直接把三个“第 1 个样本”称为一条可信场景。若未经建模便按序号连接，等价于人为加入某种依赖关系。ECC 的后续任务正是利用联合秩模板决定不同 horizon 的价格应当怎样配对。例如秩向量 $(4,5,5)$ 会从上述三盒中依次取出第 4、第 5、第 5 小的价格，形成：

```text
80 → 500 → 700
```

只有在这种跨 horizon 连接完成后，同一行的 $H$ 个价格才构成一条联合场景：

```math
\boldsymbol{x}_s
=
(x_{s,1},x_{s,2},\ldots,x_{s,H}).
```

因此可以把数据结构理解为：**每一列是某个 horizon 的 $S$ 个边际价格样本；ECC 重排后的每一行是一条覆盖全部 horizon 的场景**；纯重排不改变每列有哪些价格，只改变跨列的配对关系。每个 horizon 都生成相同数量的样本，是因为最终每条场景都要从每一列取得一个价格，并形成 $S$ 条完整路径。

需要特别注意：把每个 horizon 的 P90 直接连起来，最多只能称为一条“逐点 P90 曲线”，不能解释成“整条路径有 90% 概率发生”。P90 描述的是各 horizon 自己的边际位置；整条路径的联合概率性质还取决于跨 horizon 的依赖结构。同样，真实未来最终只产生一条实际路径，而且通常不会与任一离散场景逐点完全相同；场景集合的目标是近似联合预测分布，而不是列举所有可能未来或承诺某一行会发生。

### 10.2 端到端处理顺序

在每个决策时点 $t$，建议按以下顺序处理：

```text
构建 available_time <= t 的 Point-in-Time 快照
    ↓
取得同一 issue/cutoff 下的 P5MIN 未来 12 步锚点
    ↓
预测各 horizon 的残差分位数与负价/高价事件概率
    ↓
分位数单调化、滚动校准、构造一致边际逆 CDF
    ↓
从每个边际生成 S 个单点价格样本（此时还不是 S 条场景）
    ↓
按当前可见状态选择相似历史 residual templates
    ↓
提取模板成员在 12 个 horizon 上的联合秩
    ↓
按联合秩重新排列并连接当前边际样本
    ↓
得到 S 条 NSW1 未来 60 分钟联合价格路径及权重（每行一条场景）
    ↓
场景压缩并送入风险感知的储能滚动优化
    ↓
只执行或回测当前第一个 5 分钟动作
```

每条输出场景都应能够追溯到：

- 决策 cutoff、issue time、available time 和 12 个 target interval end；
- 使用的 P5MIN vintage；
- 边际模型、校准器、随机种子和分位数网格；
- 模板 ID、历史 anchor、距离、权重和市场 regime；
- 原始 AEMO 文件、查询参数、版本和 manifest。

### 10.3 $S$ 与“约 2,000 条场景”

$S$ 是每个边际生成的样本数，也是 ECC 完成连接后得到的原始场景数，而不是由 ECC 理论固定的常数。例如 $H=12$、$S=1{,}000$ 时，边际采样阶段产生 $12{,}000$ 个单点价格，连接后得到的是 $1{,}000$ 条 12 步场景，而不是 $12{,}000$ 条场景。

“约 2,000 条原始场景”来自更宽范围技术方案中的一个工程候选配置。该方案设想先生成较大的路径候选池，以覆盖中心、负价、普通高价、极端尖峰及其持续过程，再压缩为 30–50 条带权代表路径供随机 MPC 使用。较大的原始池可能使场景压缩有更多尾部路径可选，但 2,000 不是从本章前述公式推导出的最优值，也不是第一阶段的固定验收要求；尤其原方案覆盖的区域和 horizon 比当前 NSW1 未来 12 步范围更广，其数值不能未经验证直接沿用。

若 2,000 条场景等权，每条在离散近似中的权重为 $1/2{,}000=0.05\%$。这只是有限场景集的数值分辨率，不表示模型已经能够可靠校准 $0.05\%$ 概率的极端事件。

若相似历史模板只有 100–300 条，而希望输出约 2,000 条场景，就需要使用有权 block bootstrap、场景权重或其他明确的扩展方法。重复抽样会带来 ties 和路径重复，增加的是离散场景行数，不是同等数量的独立信息；必须检查有效样本数、场景多样性、重复率和权重集中度。

因此，$S$ 应通过时间外敏感性实验选择，而不能仅凭整数大小决定。至少应比较多个候选值和随机种子，检查边际保持误差、Energy/Variogram Score、负价与尖峰概率、持续时间、有效样本数、压缩后的尾部保持、储能首动作稳定性以及生成和求解耗时，并选择满足统计与运营稳定性要求的最小规模。

## 11. 为什么这对储能决策重要

第 3–10 章解决的是“怎样从各 horizon 的边际分布得到可信的联合价格路径”；本章说明这些路径为什么可能改变储能动作，并不引入新的预测步骤。条件 ECC 的纯重排虽然不改变每一列的边际价格样本，却会改变同一行中价格跨 horizon 的连接方式。储能优化读取的是这些完整路径，而 SOC、功率、效率、期末状态和风险约束又把不同时点连接起来，因此问题并不是 12 个互不相关的单期收益计算。

假设两个模型对**每一个未来 5 分钟 horizon**给出的边际高价概率都为 10%。

- 模型 A 把每个 5 分钟尖峰近似当成独立事件；
- 模型 B 认为一旦发生尖峰，就有较大概率连续多个区间。

这里相同的是分 horizon 的单点事件概率，不是“未来一小时内至少出现一次高价”的概率。例如 12 个区间若相互独立且各有 10% 高价概率，至少出现一次高价的概率约为 $1-0.9^{12}=71.8\%$；若这些区间完全同涨同落，该概率则可能只有 10%。这正是边际分布相同、联合路径仍然不同的含义。

一个极简例子可以更直接地说明它为什么会改变首动作。忽略费用、效率和退化，假设电池剩余能量只够放电一次，当前价格为 150 A$/MWh；两个未来 horizon 在两个模型中都分别有 50% 概率为 0、50% 概率为 200：

| 联合模型 | 50% 的路径 | 另外 50% 的路径 |
|---|---|---|
| 持续型 | $200\rightarrow200$ | $0\rightarrow0$ |
| 交替型 | $200\rightarrow0$ | $0\rightarrow200$ |

单独看任一未来 horizon，两种模型的边际分布完全相同；但如果现在保留电量，持续型模型下未来可捕获售价的期望为 $0.5\times200+0.5\times0=100$，交替型模型下则为 200。因此面对当前价格 150，前者可能倾向现在放电，后者可能倾向保留 SOC。这个例子不代表真实项目收益，只用于说明：**仅改变跨 horizon 的联合连接，也可能改变当前第一步动作。**

对本项目的 10 kW / 20 kWh 储能，同样的机制还会体现在：

- 如果尖峰只持续一个区间，电池可能不必长期保留大量 SOC；
- 如果尖峰通常持续 20–30 分钟，过早放空会损失后续高价放电机会；
- 如果高价前常有逐步抬升，控制器可能需要在风险、当前收益和未来机会成本之间权衡。

即使滚动回测每次只执行当前第一个 5 分钟动作，未来路径仍然重要，因为这个动作会改变下一时点的 SOC 和后续可行域。因此，条件 ECC 的潜在价值不是让某个 P50 自动更准，而是让滚动优化看到更可信的**尖峰开始、持续、恢复和多步组合风险**；这种潜在价值仍需通过第 14 章所述的样本外运营评价验证。

## 12. 这套方法成熟吗

应区分“基础方法成熟”和“NSW1 五分钟应用已经解决”。

| 部分 | 判断 |
|---|---|
| CDF、逆 CDF、分位数函数 | 标准概率工具，方法本身成熟 |
| 由离散分位数构造可采样分布 | 常规做法，但单调化、校准和尾部外推仍需验证 |
| 经典 ECC | 已建立的多变量后处理框架 |
| Schaake Shuffle / SimSchaake | 已建立的历史秩重排与相似状态选择方法 |
| NSW1 五分钟尖峰残差的条件模板设计 | 仍是本项目需要实证验证的研究问题 |
| 条件场景驱动的 BESS 价值 | 必须通过样本外反事实回测证明，不能由方法名称推断 |

所以，这条路线并不陈旧，也适合作为一个透明、可诊断的研究 V1；但不能因为 ECC、CDF 或 Schaake Shuffle 在其他领域已有成熟文献，就宣称它们已经解决 NEM 五分钟尖峰、制度变化、稀有事件和储能运营价值问题。

## 13. 主要局限和常见误解

### 13.1 ECC 不会修复错误的边际分布

如果 P90 实际只覆盖约 70%，或高价尾部被严重低估，重排之后仍然是错误的边际概率。必须先做好分位数单调性、覆盖率、尾部与事件概率校准。

### 13.2 完全独立与完全同秩都可能不合理

- 每个 horizon 独立抽取 $u_h$，等于施加独立性；
- 所有 horizon 使用同一个 $u$，等于施加极强的同秩关系；
- ECC 式方法用历史经验秩来决定 $u_1,u_2,\ldots,u_{12}$ 怎样组合。

### 13.3 它难以创造历史从未出现过的依赖结构

如果历史中没有“极端需求 + 风电骤降 + 多个联络线受限 + 机组跳机”这种组合，经验模板很难凭空生成可靠的新结构。遇到分布外（Out-of-Distribution, OOD）状态时，应显式标记、扩大不确定性，并与无条件模板、参数 Copula 或压力场景等回退方案比较。

### 13.4 相似度定义可能比重排本身更重要

若模板选错，ECC 会忠实地恢复一套错误的依赖结构。因此近期价格路径、事件阶段、reserve、联络线和 constraint 等特征的可见性、变换和权重，需要通过消融与时间外回测选择，不能只靠主观设定。

### 13.5 不能用今天的未来结果挑模板

这是最危险的泄漏方式。选择模板时只允许使用 $t_0$ 已知的信息；历史 anchor 之后的实际残差只能在 anchor 已经被选中后作为模板载荷使用。

### 13.6 “条件 ECC”不是自动等同于生产可用

本项目目前是离线研究环境。场景即使统计上更合理，也必须继续接受物理约束、费用假设、SOC 连续性、NMI 能量守恒和样本外运营价值检验。

### 13.7 Rank、分位位置和场景概率不能互换

Rank 是列内相对名次，$u$ 是由名次得到的边际概率坐标，$Q_h(u)$ 是该坐标对应的当前价格，$w_m$ 才是整条场景参与期望或风险计算的权重。把 P90 场景写成“有 90% 概率发生”，或把每个 horizon 的 P90 连线解释为“整条路径有 90% 概率发生”，都会错误地把边际位置当成联合事件概率。

## 14. 怎样判断它是否真的更好

不能只看几条场景是否“顺眼”，至少需要三层评价。

### 14.1 边际概率质量

- 分 horizon 的 P10、P50、P90 pinball loss；
- P10–P90 覆盖率与区间宽度；
- 分位数交叉率；
- 负价和参数化高价事件的 Brier score 与校准曲线；
- 如输出完整分布，再报告 CRPS、PIT 或 WIS。

### 14.2 联合路径质量

- 相邻 horizon 的 rank correlation；
- 五分钟 ramp 分布；
- 高价、负价和尖峰持续时间；
- Energy Score 与 Variogram Score；
- 场景多样性、重复率和权重集中度；
- 如未来扩展多区域目标，再检验跨区域传播和共同尾部事件。

### 14.3 储能运营价值

至少公平比较：

1. 原始 P5MIN 驱动的滚动策略；
2. 独立边际采样；
3. 无条件历史 Shuffle；
4. 条件 ECC / SimSchaake 风格场景；
5. 完美预知上界，仅用于机会空间估计。

运营指标应包括参数化费用、损耗和退化下的增量净收益、regret、回撤、尖峰捕获率、SOC 机会成本和约束违例。预测指标改善但样本外运营价值下降，或运营价值改善但概率严重失准，都不能称为全面改进。

## 15. 推荐的透明研究 V1

第一版不必先训练复杂网络学习相似度。一个更容易审计的起点是：

```math
\boxed{
\text{Regime 硬过滤}
+
\text{稳健标准化}
+
\text{加权 KNN}
+
\text{距离加权模板抽样}
+
\text{历史残差联合秩重排}
}
```

建议遵循以下顺序：

1. 固定 Point-in-Time 数据契约和 P5MIN vintage 规则；
2. 实现 P5MIN、持久性、季节性和简单 P5MIN 校准基线；
3. 先证明边际分位数与事件概率可靠；
4. 实现无条件 Shuffle 作为联合基线；
5. 加入硬过滤和手工透明权重的条件模板；
6. 用时间顺序验证集选择 $K$、$\tau$、特征组和回退规则；
7. 做独立采样、无条件 Shuffle 与条件 ECC 的消融；
8. 最后再研究自动学习相似度、t-Copula 或生成式联合模型。

每一步都应能够回答：使用了哪些当时可见输入、输出了什么概率信息、相对原始 P5MIN 改善还是退化、是否改变了储能动作与风险，以及结论对费用和合成资产假设是否敏感。

## 16. 最后再用一句比喻收尾

> **分位数模型和逆 CDF 决定今天有哪些演员；相似历史残差决定选哪类剧本；ECC 式重排决定演员如何站到同一条时间线上。**

目标不是生成“看起来平滑”的曲线，而是在不破坏每个 horizon 边际概率的前提下，构造可追溯、无未来信息泄漏、统计上经过校准，并且能改善样本外储能决策的 NSW1 联合价格场景。
