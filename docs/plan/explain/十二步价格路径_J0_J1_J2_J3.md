# 十二步价格路径 J0/J1/J2/J3

> 教学说明，不新增主方案契约。正式路径不变量、模板资格和评价以主技术方案第 7 章为准。

## 1. 为什么有边际分布后还要路径

第 6 章回答每个 horizon 的价格分布，例如 14:05、14:10、...、15:00 分别可能是多少。储能还关心这些价格如何共同出现：

- 负价是否连续；
- 尖峰是否持续；
- ramp 是否平滑或剧烈；
- 高价前是否需要保留 SOC。

可以把单个 horizon 的分布看成“照片”，把 12 步联合路径看成“一小时价格电影”。

## 2. 共同边际候选

对当前每个 horizon 的校准 CDF $F_{t,h}$，先生成 $S$ 个等概率候选：

```math
q_j=\frac{j-0.5}{S},\qquad X_{(j),h}=F^{-1}_{t,h}(q_j)
```

这里 $j$ 是固定 horizon 内从低到高的候选索引，不是场景编号。到这一步，只知道每一列有哪些候选价格，还不知道哪些值横向连成同一条路径。

## 3. J0：独立边际采样

J0 对每个 horizon 独立抽一个排列：

```math
Y_{t,h}^{(s)}=X_{(\pi_h(s)),h}
```

它严格保留每一列的候选价格多重集合，但不引入跨时间依赖。用途是判断“只用边际分布、不建模路径联系”会怎样。

## 4. J1：历史残差块重采样

J1 抽取历史完整残差块：

```math
e_{i,h}=y_{i,h}-a_{i,h},\qquad Y_{t,h}^{(s)}=a_{t,h}+e_{i_s,h}
```

它借历史误差金额和形状，保留一小时残差块的持续性，但不保证生成结果符合当前校准 CDF。因此 J1 是端到端简单基线，不能与 J0/J2/J3 一样解释为“只改变依赖结构”。

## 5. J2：无条件 PIT/Schaake 重排

J2 从合格历史 PIT 模板中无条件选择 $S$ 条，对每个 horizon 按 PIT 排名，再把今天的候选价格按秩分配：

```math
Y_{t,h}^{(s)}=X_{(\rho_{s,h}),h}
```

它不搬历史价格金额，只借历史“高低秩次序”，因此保留当前离散边际样本。

## 6. J3：条件 PIT/Schaake 重排

J3 与 J2 的生成公式相同，只是在选择模板时按当前可见状态 $z_t$ 与历史起点当时可见状态 $z_i$ 的相似度检索。它的研究问题是：相似历史的 PIT 秩是否比全局历史 PIT 秩更适合当前状态。

## 7. 关键对比

| 方法 | 借什么 | 是否保持当前边际候选 | 是否按当前状态选历史 |
|---|---|---:|---:|
| J0 | 不借历史依赖 | 是 | 否 |
| J1 | 历史残差金额块 | 否 | 基础版否 |
| J2 | 历史 PIT 秩 | 是 | 否 |
| J3 | 相似历史 PIT 秩 | 是 | 是 |

J3 只有在相对 J2 改善路径质量、首动作或风险调整净价值，且无泄漏和支持度充分时，才应晋升。
