# 残差概率模型 M0/M1/M2

> 教学说明，不新增主方案契约。正式定义、训练切分、校准与评价以主技术方案第 6 章为准。

## 1. 为什么预测残差

第一阶段不直接从零预测 NSW1 RRP，而是先使用决策截点前最新可见的 P5MIN NSW1 RRP 作为锚点：

```math
Y_{t,h}=A_{t,h}+E_{t,h}
```

- $Y_{t,h}$：目标五分钟区间最终使用的 NSW1 RRP 标签；
- $A_{t,h}$：当时可见的 P5MIN 预测；
- $E_{t,h}$：P5MIN 的误差，定义为 `actual - anchor`。

例如 P5MIN 预测 100 A$/MWh，实际为 130，则残差为 +30，表示 P5MIN 低估 30；实际为 70，则残差为 -30，表示 P5MIN 高估 30。

若模型输出残差分位数 $Q_E(\alpha)$，价格分位数就是：

```math
Q_Y(\alpha)=A+Q_E(\alpha)
```

这是在给已知锚点加一个误差概率层，不是把两个未知随机变量的分位数随意相加。

## 2. M0：P5MIN 条件经验残差

M0 的问题是：

> 过去类似情况下，P5MIN 通常错多少？

做法是按 horizon、时段、季节、P5MIN 价格状态等预注册条件，在合格历史样本中统计残差经验分布。首版可以从较粗分组开始，样本不足时向更宽历史池收缩，避免用极少数极端样本输出虚假窄区间。

示例：当前 P5MIN 锚点为 120；历史同类残差 P10/P50/P90 为 -40/0/+70，则价格 P10/P50/P90 为 80/120/190。

M0 是强概率基线，不是“随便的弱模型”。候选模型必须先相对 M0 证明概率增量。

## 3. M1：LightGBM 残差分位数模型

M1 的问题是：

> 根据当前更丰富的可见市场状态，这一次 P5MIN 可能错多少？

它仍预测残差，但用 LightGBM 学习非线性特征组合，例如：

- 当前 P5MIN 曲线水平、斜率和 revision；
- 最近可见 NSW1 实际价格与波动；
- 需求、备用、联络线 headroom；
- QLD1/VIC1 等可见辅助特征；
- 数据质量和时段状态。

首版采用 pooled-horizon quantile model：同一分位水平一套模型，`horizon_step` 作为显式特征，共享 h=1...12 的训练信息。它不是 12 步联合路径模型；跨 horizon 依赖仍由路径模块处理。

M1 必须与 M0 在相同 issue、target、价格版本和样本规则下比较。

## 4. M2：事件概率模型

M2 专门回答运营关键事件：

```math
P(RRP < 0), \qquad P(RRP > \theta)
```

其中 $\theta$ 是实验预注册的高价阈值。300、1000、5000 A$/MWh 可以是诊断候选，但不能自动等同于统一阈值或历史市场上限。

M2 可用二分类 LightGBM 并经过概率校准。稀有事件训练可加权或过采样，但评价必须恢复真实发生率，并报告 episode 数。

## 5. 三者不是逐级替换

```text
M0 = 历史老师：类似历史下 P5MIN 通常错多少
M1 = 机器学习分析师：当前复杂状态下这次可能错多少
M2 = 事件报警器：负价/高价事件概率是多少
```

合理关系是：M0 作为强基线和降级方案，M1/M2 作为候选概率流水线的互补组件。是否采用复杂组合，由时间外概率校准、事件评分和运营价值共同决定。
