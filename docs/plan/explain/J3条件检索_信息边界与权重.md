# J3 条件检索的信息边界与权重

> 教学说明，不新增主方案契约。正式 J3 选择、治理、回退和晋升门以主技术方案第 7.7–7.10 节为准。

## 1. J3 一句话

J3 先用当前和历史起点当时可见的信息找到相似历史，再借这些历史模板的 PIT 高低秩次序连接今天自己的价格候选。

它不是重新预测边际价格，也不搬历史价格金额。

## 2. 两阶段机制

### 阶段 A：条件检索

```math
P(i\mid t)\propto \mathbf 1_{eligible_i}K\left(\frac{d(z_t,z_i)}{b}\right)
```

这一阶段只使用：

- 当前起点可见状态 $z_t$；
- 历史起点当时可见状态 $z_i$；
- 模板资格、版本和治理信息。

不能使用历史起点后的实际价格、残差、PIT、未来事件结果或未来约束判断相似度。

### 阶段 B：PIT 重排

入选 $S$ 条模板后，才读取它们的完整 PIT 路径。每个 horizon 单独排名，并把今天的候选价格按秩分配：

```math
Y_{t,h}^{(s)}=X_{(\rho_{s,h}),h}
```

同一模板身份贯穿全部 horizon，不能拼接不同历史起点。

## 3. 历史模板的 A 区和 B 区

```text
A 区：历史起点当时已可见
  P5MIN、revision、近期 RRP、需求、网络、时段、数据质量、as-of 概率摘要

B 区：结果揭晓后才形成
  实际价格、残差、PIT、episode 结果、template_eligible_at
```

J3 的边界是：选模板时只读 A 区；资格检查可读 B 区完成时间和质量；入选后才读 B 区 PIT。

## 4. 为什么入选后仍等权

相似度权重回答“哪些历史更容易入选”。入选后，原始场景通常等权：

```math
w_s=1/S
```

这样相似度只在抽样阶段作用一次。若入选后再按相似度加权，会二次放大近邻，并可能破坏每个 horizon 等概率候选所表示的当前离散边际。

如果后续做场景压缩，权重可变为被代表场景的概率质量总和，但必须重新校验边际、尾部和首动作。

## 5. 两类非法用法

1. **使用尚未完整揭晓的模板**：例如当前 14:00，却使用 13:30 起点的完整一小时模板，其中 14:05–14:30 的结果尚不可见。
2. **用历史结局挑模板**：例如只选择后来真的发生高价的历史起点来匹配今天的上行风险。

合法流程不要求忘记历史结果，而是要求历史结果只能在当前 cutoff 前已合格，并且不能倒流进相似度特征。

## 6. J3 晋升问题

J3 相对 J2 只有一个主动差异：是否按当前状态选模板。晋升至少需要证明：

- 无未来信息泄漏；
- 模板支持度和事件支持度足够；
- 路径评分或 episode 持续性改善；
- 首动作、风险或净价值有时间外增量；
- 带宽、特征和治理规则敏感性可接受。
