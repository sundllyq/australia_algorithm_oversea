# S1/S2 表后结算和费用口径

> 教学说明，不新增主方案契约。正式结算字段、费用情景和回测口径以主技术方案第 8、10 章为准。

## 1. RRP 如何进入用户侧价格

模型预测的是 NSW1 RRP，单位 A$/MWh。结算模块先转为 A$/kWh：

```math
spot\_price=RRP/1000
```

再叠加参数化费用：

```math
import\_price=spot\_price+import\_adders
```

```math
export\_price=spot\_price+export\_adjustments
```

进口附加费和出口调整项必须声明单位、方向、适用能量、来源和有效期。缺失费用不能静默设为零；Gross-RRP 只能称毛价值诊断。

## 2. S1：纯价格信号

S1 不引入负荷和光伏，只看电池如何响应 NSW1 价格信号。它适合隔离预测、路径和优化的贡献，但不能称为真实表后用户收益。

## 3. S2：合成表后站点

S2 引入合成负荷/PV、NMI 进口/出口和本地价值优先规则。核心能量守恒是：

```math
P^{imp}-P^{exp}=P^{load}-P^{pv}+P^c-P^d
```

优化器只能读取决策截点时可用的负荷/PV 预测，结算才使用事后实现轨迹。若合成轨迹被设为完全可知，必须明确标注为确定性合成假设。

## 4. 本地价值优先和市场 overlay

本地价值优先可理解为两层：

1. C1 本地策略先根据负荷/PV、备用和本地规则确定本地动作或保留包络；
2. 市场 overlay 只能使用剩余功率、能量和 NMI headroom 响应 RRP。

必须分别记录 `local_service_action` 与 `market_overlay_action`，并防止同一 kWh 同时获得避免购电价值和出口收入。
