# 分位数、CDF 与事件概率一致化

> 教学说明，不新增主方案契约。正式 CDF 构造、校准和评价以主技术方案第 6 章为准。

## 1. P10/P50/P90 表达什么

P10、P50、P90 是同一个预测分布上的三个位置：

| 分位数 | 直观含义 | 不是 |
|---|---|---|
| P10 | 约 10% 的概率在它以下 | 最低可能价格 |
| P50 | 中位数 | 一定会发生的价格 |
| P90 | 约 90% 的概率在它以下 | 最高可能价格 |

例如 P10=80、P50=120、P90=190，可以理解为中央约 80% 区间是 80–190。但这只是预测声明，实际覆盖率要用时间外数据检验。

## 2. 为什么 P10/P50/P90 不等于完整分布

三个分位点不足以唯一确定 CDF，也不足以诚实生成大量场景。两个不同分布可以有相同的 P10/P50/P90，却有不同尾部、不同负价概率和不同高价概率。

因此优化内部需要更密的分位数网格、单调化、事件融合、插值和尾部规则，例如：

```text
P01, P2.5, P05, P10, P25, P50, P75, P90, P95, P97.5, P99
```

## 3. 分位数与事件概率为什么可能冲突

假设连续分布中 P90=300，通常意味着 300 上方约 10% 概率。但事件模型又给出：

```math
P(RRP > 300)=20\%
```

这两者不可能同时属于同一个连续 CDF。存在点质量时还要区分左极限和右连续 CDF，但核心问题相同：不能让优化器同时消费互相矛盾的概率数字。

## 4. 一致化的基本思路

把分位数、事件概率和市场规则边界统一映射为 CDF 约束节点：

```text
分位数节点：     (Q(alpha), alpha)
负价左限节点：   (0-, P(Y<0))
高价节点：       (theta, 1-P(Y>theta))
规则支持域：     floor/cap 及其生效版本
```

然后进行有记录的单调投影、插值和尾部构造。输出必须满足：

- CDF 随价格非递减；
- 概率位于 [0,1]；
- 分位数顺序正确；
- 高价阈值越高，超越概率不增加；
- 不越过目标时点有效市场规则支持域。

一致化只保证数学合法，不保证校准。最终还需要 pinball loss、覆盖率、Brier score、PIT/CRPS 等时间外评价。
