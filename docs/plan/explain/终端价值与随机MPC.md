# 终端价值与随机 MPC

> 教学说明，不新增主方案契约。正式优化约束、CVaR、信息结构和终端价值以主技术方案第 8–9 章为准。

## 1. 为什么一小时窗口需要终端价值

电池可用能量 20 kWh，功率 10 kW，从低 SOC 充满大约需要两个小时。一小时 MPC 若把窗口末剩余电量视为零价值，容易在第 12 步附近近视放空；若每轮硬性回到 50% SOC，又会压制跨小时套利。

终端价值 $V(E_{H+1},ctx)$ 给窗口末库存一个延续价值近似。它不是已实现现金流，也不能在每个五分钟回测 PnL 中重复计入。

## 2. O0/O1/O2 怎么理解

| 编号 | 含义 | 用途 |
|---|---|---|
| O0 | Open-loop，12 步动作对所有场景相同 | 最保守、易验证基线 |
| O1 | 多阶段场景树，动作只能随已观察前缀分叉 | 随机 MPC 主候选 |
| O2 | 第二步起每条完整路径独立决策 | 乐观完美信息 recourse 诊断，不可实施 |

实际回测每五分钟都会重新优化，所以当前窗口内第 2...12 步计划只用于估计首动作机会成本，不代表未来会照旧执行。

## 3. CVaR 在这里惩罚什么

主风险项使用相对安全策略的增量损失：

```math
\Delta G_s=G_s-G^{safe}_s,\qquad L_s=\max(0,-\Delta G_s)
```

然后在期望增量价值中扣除损失上尾 CVaR。这样风险项不被共同的站点负荷成本或无关价格波动主导。

CVaR 的置信水平、权重、安全策略和是否包含终端价值都必须在实验配置中冻结。

## 4. V0/V1/V2 的定位

| 方法 | 直观定位 | 注意点 |
|---|---|---|
| V0 | 零终端价值 | 诊断近视效应，不推荐作默认 |
| V1 | 训练期历史延续价值表 | 使用历史实际未来价格求延续价值，带完美预知偏乐观风险 |
| V2 | cutoff 前可见 Predispatch 延续价值 | 数据门控 challenger，需审计 vintage 和偏差 |

V1 是带折扣和冻结校准的离线近似，不是现实可执行策略。若它导致异常囤电、SOC 贴边或收益由终端调整主导，应回退或重估。

## 5. 回测 PnL 与终端价值

连续回测只结算实际执行的五分钟能量与费用。每轮优化输出的 `expected_terminal_value_aud` 是诊断字段，不进入已实现 PnL。整段评价期末只能按共同规则记一次终点 SOC 调整，防止候选策略通过留下未计价电量虚增收益。
