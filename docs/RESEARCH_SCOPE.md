# 研究范围与阶段契约

## 一句话定义

本项目研究如何在每个 5 分钟决策时点，利用 AEMO P5MIN 和其他当时可见的数据，输出未来 1 小时 NSW1 RRP 的概率预测，并验证这些预测是否能提高新南威尔士州小型表后储能的风险调整增量净收益。

预测、控制和收益计算均为离线研究。第一阶段不连接真实设备，不执行真实市场报价，也不代表任何实际用户合同。

## 核心研究问题

第一阶段围绕以下问题组织实验：

1. 原始 P5MIN 对未来 12 个 NSW1 RRP 区间的概率信息有多大局限？
2. 对 P5MIN 做概率校准或残差学习，是否比完全独立预测更稳定？
3. 哪些数据链路在严格 as-of 对齐后仍能提供样本外增量信息？
4. 模型是否能改善负价、高价和尖峰事件的概率判断，而不只是平均误差？
5. 概率更准确是否会改善储能的充放电时机、风险和净收益？
6. 改善是否在不同 horizon、月份、时段和价格状态中稳定？
7. 结果对费用、效率、退化、备用 SOC 和预测误差有多敏感？

## 第一阶段预测任务

在每个模型 issue time t 输出：

    NSW1 RRP(t + 5 分钟)
    NSW1 RRP(t + 10 分钟)
    ...
    NSW1 RRP(t + 60 分钟)

每个目标至少输出 P10、P50 和 P90。模型接口还应允许：

- 更多分位数；
- 负价概率；
- 超过一个或多个参数化高价阈值的概率；
- 完整参数分布；
- 经校准的联合情景样本。

输出结构采用长表，每行表示一个 issue time、target interval、horizon 和预测版本。不得使用固定长度数组作为唯一持久化格式，因为后续需要扩展到更长 horizon。

## P5MIN 的研究路径

第一阶段至少形成四条可独立复算的数据与模型链路：

### 链路 A：原始 P5MIN

直接使用决策时最新可见的 P5MIN NSW1 RRP，建立官方基线和储能决策基线。

### 链路 B：P5MIN 概率校准

按 horizon、时段、季节或市场状态估计 P5MIN 误差分布，输出条件分位数和事件概率。这是第一项必须完成的概率模型能力。

### 链路 C：P5MIN 残差学习

预测实际 RRP 与 P5MIN RRP 的残差分布。输入可包括：

- 当前 12 点 P5MIN 曲线；
- 同一目标在相邻 run 中的修订；
- 最近实际 NSW1 RRP；
- 决策时可见的需求、发电、联络线和约束信息；
- 日历及后续验证可用的天气信息。

### 链路 D：独立模型与集成

建立不依赖 P5MIN 点值的模型和包含 P5MIN 的集成模型，用消融实验判断 P5MIN 的实际贡献。

## 储能研究场景

### 场景 1：纯价格信号基准

使用 10 kW / 20 kWh 可用能量的小型储能，不引入真实站点负荷和光伏，用于隔离预测质量对充放电决策的影响。该场景只能解释预测的运营代理价值，不能称为完整表后用户收益。

### 场景 2：合成表后站点

在相同储能上增加可复现的合成负荷、光伏、进口/出口限制和本地价值优先逻辑。分别构造户用或极小型商业参数情景，但不得将合成结果外推为真实项目。

真实站点数据未来可作为新的数据适配层接入，不改变预测、决策和结算的核心接口。

## 范围内成果

第一阶段的最小成果包括：

- NEMSEER P5MIN 与 NEMOSIS 实际价格的数据审计；
- 可追溯的 NSW1 forecast-vintage 长表；
- 每个 issue time 对应的未来 12 步标签；
- 原始 P5MIN、持久性和季节性基线；
- 至少一个概率 P5MIN 校准模型；
- 至少一个概率残差或机器学习模型；
- 分 horizon 的概率、事件和点预测报告；
- 使用原始 P5MIN 与自研模型的滚动储能回测；
- 低、中、高费用与关键资产参数敏感性；
- 概率指标相对 P5MIN 校准基线，以及点预测和运营价值相对原始 P5MIN 的结论；
- 完整实验 manifest、配置和局限说明。

## 明确不在第一阶段

- 真实 EMS 或逆变器控制；
- 实时数据服务和生产 SLA；
- 实际零售、VPP 或 FRMP 合同复刻；
- 市场注册、报价、计量与合规实施；
- FCAS 或其他收入叠加；
- 多站点聚合；
- 跨区域交易或跨区域收益；
- 对 NSW1 以外区域的适用性声明；
- 以完美预知收益作为部署预期。

## 阶段路线

### M0：契约和环境

冻结本文档、数据契约、预测协议、回测协议以及 Python 和依赖版本。

### M1：数据审计

用小时间窗口验证表、字段、时间、区域、forecast run、actual price、重复、缺失和缓存行为，再扩展到完整月份。

### M2：共同历史数据集

构建 2021-10-01 之后的共同可用区间，保留所有 P5MIN vintages，并冻结最新完整 12 个月作为最终滚动测试候选。

### M3：概率基线

复现原始 P5MIN，并首先建立 P5MIN 条件误差和分位数校准模型。

### M4：数据链路与模型比较

增加残差模型、市场特征、独立模型和集成模型，进行严格消融。

### M5：储能运营价值

完成纯价格信号和合成表后场景的滚动回测、费用和资产敏感性。

### M6：结论

给出哪些模型在何种 horizon 和价格状态下优于 P5MIN、是否产生运营价值、结果依赖哪些假设，以及下一阶段应继续或停止的方向。

## 第一阶段完成定义

仅当以下条件同时满足时，第一阶段才可称为完成：

- 概率预测而非只有点预测；
- 最新 12 个月的时间滚动样本外结果；
- 原始 P5MIN 使用相同信息边界公平比较；
- 负价、高价和普通价格状态分别报告；
- 至少一个使用概率信息的滚动储能策略；
- 所有收益包含显式费用和退化情景；
- 完美预知仅作为上界；
- 结果可从 manifest、配置和数据快照复算；
- 对合成资产、合同和可见时间代理的限制做出明确声明。
